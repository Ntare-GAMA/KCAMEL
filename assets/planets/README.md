# Planet images

Put your planet images in this folder using these exact file names.
Transparent PNG (or WebP renamed to .png) looks best: the planet on an empty background.

| File name        | Where it appears                                  |
|------------------|---------------------------------------------------|
| hero.png         | Big planet in the bottom-right of the home screen  |
| about.png        | Small planet floating beside "Who We Are"          |
| film.png         | Portfolio system – the FILM planet                 |
| music.png        | Portfolio system – the MUSIC planet                |
| commercial.png   | Portfolio system – the COMMERCIAL planet           |
| experience.png   | Planet beside "Our Experience"                     |
| contact.png      | Planet beside "Start a Conversation"               |

If a file is missing, the site paints its own planet in that spot, so you can add them one at a time.
